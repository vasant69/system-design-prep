### Rapid-Fire Round — 25 Trap Questions

1. **Struct ya class — agar keyword hi na likhein to default kya hota hai?** Trick question hai — C# me `struct`/`class` keyword likhna hi mandatory hai, "default" jaisa kuch exist nahi karta, syntax hi invalid hoga bina keyword ke.

2. **`int` value type hai ya reference type?** Value type — `struct` hai (`System.Int32`), stack pe (ya container ke andar inline) allocate hota hai, copy-by-value semantics follow karta hai.

3. **Kya C# multiple class inheritance allow karta hai?** Nahi — ek class sirf ek base class se inherit kar sakti hai. Multiple interfaces implement kar sakti hai.

4. **`private protected` ka matlab kya hai?** Intersection — protected AND internal — same assembly ke andar derived classes hi access kar sakti hain, bahar ki assembly ki derived class nahi.

5. **`protected internal` ka matlab kya hai?** Union — protected OR internal — same assembly me koi bhi code, YA kisi bhi assembly ki derived class, dono access kar sakte hain.

6. **Static constructor kitni baar chalta hai?** Sirf ek baar — pehli baar type use hone se pehle, CLR automatically call karta hai, tum explicitly call nahi kar sakte.

7. **`Equals()` override karo to `GetHashCode()` bhi override karna kyun zaroori hai?** Contract hai — do equal objects ka same hash code hona chahiye, warna `Dictionary`/`HashSet` jaisi hash-based collections silently break ho jaati hain.

8. **`==` operator class pe default kya karta hai?** Reference equality check karta hai (same memory location), value equality nahi, jab tak explicitly override na kiya ho.

9. **Method hiding (`new`) vs overriding (`override`) — base-type reference se call karne par kaunsa method chalega?** Hiding me base class ka method chalega (compile-time/static type se resolve hota hai); overriding me derived class ka method chalega (runtime type se resolve hota hai).

10. **`abstract` class instantiate ho sakti hai?** Nahi, kabhi nahi — `new AbstractClass()` compile error deta hai, chahe usme concrete members hi kyun na ho.

11. **Interface me constructor ho sakta hai?** Nahi — interfaces me constructors allow nahi hain, sirf abstract classes me ho sakte hain (derived classes ke `base()` calls ke liye).

12. **Ek class kitni interfaces implement kar sakti hai?** Unlimited — jitni chahiye utni, ye multiple class inheritance jaisi restriction interfaces pe apply nahi hoti.

13. **`sealed` class ko inherit kiya ja sakta hai?** Nahi — `sealed` specifically further inheritance ko block karta hai.

14. **Boxing kab hoti hai?** Jab ek value type ko `object` type (ya kisi interface type) me assign kiya jaata hai — value heap pe wrap ho jaati hai.

15. **`init`-only property kab set ho sakti hai?** Sirf object initialization ke during (constructor ya object initializer syntax ke andar) — uske baad kabhi nahi, `readonly`-jaisa but object-initializer-syntax-friendly.

16. **`required` member kab introduce hua, aur kya enforce karta hai?** C# 11 (2022) — compiler force karta hai ki us member ko object creation ke waqt (constructor ya initializer se) value diya hi jaaye, warna compile error.

17. **Compile-time polymorphism kaunsa hai — overloading ya overriding?** Overloading — compiler compile-time pe hi decide kar leta hai kaunsa overload call hoga, based on argument types/count.

18. **Overload resolution me priority kya hai — exact match ya implicit conversion?** Exact match sabse pehle try hota hai, phir implicit conversion, phir `params` array — is order me.

19. **`record` type ki default equality kaisi hai — reference ya value?** Value-based (structural) equality by default — do `record` instances equal hain agar unke saare properties equal hain, chahe alag objects hi kyun na hon.

20. **Extension method kya actually karta hai underlying?** Compile-time syntactic sugar hai — ek static method ka regular call, jisme first parameter `this` se marked hota hai. Type ke andar koi naya member add nahi hota.

21. **Singleton service lifetime me ek Scoped dependency inject karna kyun dangerous hai?** Captive dependency problem — Singleton lifetime me capture hui Scoped instance apni intended per-request lifetime se zyada der tak zinda reh jaati hai, stale/shared state ka risk.

22. **`ControllerBase` aur `Controller` me kya farak hai?** `Controller`, `ControllerBase` ko extend karta hai aur extra view-support members (jaise `View()`) add karta hai — pure Web APIs ko sirf `ControllerBase` chahiye.

23. **DIP (Dependency Inversion Principle) aur DI (Dependency Injection) same cheez hain?** Nahi — DIP ek design PRINCIPLE hai (high-level modules abstractions pe depend karein), DI ek TECHNIQUE hai dependencies supply karne ki. DI ke bina bhi DIP follow ho sakta hai (manual factory), aur DI use karke bhi DIP violate ho sakta hai (concrete class inject karna).

24. **Liskov Substitution Principle `Square : Rectangle` me kyun break hota hai?** Kyunki `Square` ka `SetWidth` implicitly `Height` bhi change kar deta hai — ye base class (`Rectangle`) ke expected behavior contract ko violate karta hai, caller assume karta hai `SetWidth` sirf width change karega.

25. **Async constructor likh sakte ho kya?** Nahi — constructor hamesha fully-constructed object synchronously return karta hai, `async` fundamentally `Task` return karta hai, ye contracts incompatible hain. Workaround: static async factory method.

</Hinglish>

## Common Mistakes

<Mistake>

</Mistake>

<Mistake>

</Mistake>

<Mistake>

`private protected` aur `protected internal` ko mix up karna under pressure — ye is list ka sabse common real mistake hai, dono naam bahut similar sound karte hain.

</Mistake>

</Mistake>

## Quick Revision

<QuickRevision>

- Rapid-fire is a pacing test, not a depth test — one-liner, confident, correct, then move on
- `private protected` = intersection (protected AND internal); `protected internal` = union (protected OR internal)
- Hiding (`new`) resolves by compile-time reference type; overriding (`override`) resolves by runtime object type
- `Equals()`/`GetHashCode()` must always be overridden together — hash-based collections break silently otherwise
- Multiple class inheritance is disallowed in C#; multiple interface implementation is unlimited
- DIP is a principle, DI is a technique — they're independently satisfiable, not the same thing
- Async constructors don't exist — the workaround is a static async factory method
- If any answer above felt shaky, revisit that topic's full deep-dive rather than just re-memorizing the one-liner

</QuickRevision>
