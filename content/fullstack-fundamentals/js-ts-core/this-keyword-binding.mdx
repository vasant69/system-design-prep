## 1. Concept Overview

`this` lexical **nahi** hai. Ye **call time** par bind hota hai, is baat se ki function kaise call hua. Rules, priority order me:

1. **`new` binding** — `new Fn()` `this` ko naye bane object par set karta hai.
2. **Explicit binding** — `fn.call(obj)`, `fn.apply(obj)`, ya `fn.bind(obj)` se bana function `this` ko `obj` par set karta hai.
3. **Implicit binding** — `obj.fn()` `this` ko `obj` par set karta hai (dot ke left wali cheez).
4. **Default binding** — plain `fn()` strict mode me `this` ko `undefined` par set karta hai (sloppy mode me `globalThis`).

**Arrow functions** ye sab ignore karte hain: unka apna `this` nahi hota aur wo us scope ka `this` use karte hain jahan wo define hue. Isiliye arrows "maine callback me `this` kho diya" ka fix hain.

- **`call(thisArg, ...args)`** — abhi invoke, arguments listed.
- **`apply(thisArg, argsArray)`** — abhi invoke, arguments array me.
- **`bind(thisArg, ...args)`** — ek naya function return jo permanently `thisArg` se bound hai (aur optionally pre-filled args). Bind jeet jaata hai; use re-bind nahi kar sakte.

## 2. Core Syntax

```js
const person = {
  name: 'Ravi',
  greet() { return `Hi, ${this.name}`; },
};

person.greet();                       // "Hi, Ravi"      -> implicit: left of the dot

const g = person.greet;
g();                                  // "Hi, undefined" -> default: bare call, this = undefined

g.call({ name: 'Sara' });             // "Hi, Sara"      -> explicit
g.apply({ name: 'Sara' });            // same, args as array
const bound = g.bind({ name: 'Mia' });
bound();                              // "Hi, Mia"       -> permanently bound
bound.call({ name: 'X' });            // "Hi, Mia"       -> bind cannot be overridden

// arrow: this from enclosing scope
const obj = {
  name: 'Kai',
  delayed() {
    setTimeout(() => console.log(this.name), 0);   // arrow -> this is obj -> "Kai"
    setTimeout(function () { console.log(this?.name); }, 0); // plain -> this = undefined
  },
};
```

```js
// borrowing a method with call/apply
Array.prototype.slice.call(arguments);          // turn array-like into array
Math.max.apply(null, [3, 1, 9]);                // spread an array as args (pre-ES6)
Math.max(...[3, 1, 9]);                         // modern equivalent
```

## 3. Working Example

Callback me `this` khone ka fix.

```js
class Timer {
  seconds = 0;

  // field arrow -> this is the instance, always
  tickArrow = () => { this.seconds++; };

  // method -> this depends on how it is called
  tick() { this.seconds++; }

  startBroken() {
    setInterval(this.tick, 1000);          // BUG: called as bare fn -> this = undefined -> throws
  }
  startFixedBind() {
    setInterval(this.tick.bind(this), 1000);   // explicitly bind
  }
  startFixedArrow() {
    setInterval(() => this.tick(), 1000);      // wrapper arrow keeps this
  }
  startFixedField() {
    setInterval(this.tickArrow, 1000);         // arrow field is pre-bound
  }
}
```

`this.tick` akela bas ek function reference hai; `setInterval` use plain call karta hai, isliye `this` `undefined` hai aur `this.seconds++` throw karta hai. Teeno fixes chalte hain; arrow field class components me sabse common hai.

## 4. Common Mistakes / Interview Traps

- **"Arrow functions `this` ko object par bind karte hain."** Nahi — unka `this` hota hi **nahi**; wo lexically inherit karte hain. Object literal par arrow method surrounding scope se `this` leta hai (aksar module), object se nahi.
- **`obj.method` ko callback ki tarah pass karna** aur expect karna ki `this` survive karega. Nahi karta — extract-then-call default binding hai.
- **`bind` naya function return karta hai.** `fn.bind(x)` `fn` ko mutate nahi karta; return value use karni padti hai. Double `bind` ka pehle ke baad koi effect nahi.
- **Method ke andar plain nested `function` me `this`** — wo `undefined` hai, outer object nahi. Arrow use karo ya `const self = this` capture karo.
- **Arrow function ke saath `new`** -> `TypeError`, arrows constructable nahi.
- **`call`/`apply` ke saath `null` thisArg** strict mode me `this` ko `null` chhodta hai, global object nahi.
- **Event handlers**: regular `function` handler ka `this` = DOM element; arrow handler ka `this` enclosing scope se.

## 5. Practice Task

Diya hua:

```js
const obj = {
  name: 'A',
  greet() { return 'hi ' + this.name; },
};
```

`greet` ke **chaar** call sites banao taaki `this.name` resolve ho:

1. `'A'` (aise call karo ki implicit binding lage)
2. `undefined` (aise call karo ki default binding lage)
3. `'B'` — `call` ya `apply` se `{ name: 'B' }` ke saath
4. `'C'` permanently — `bind` se, aur phir dikhao ki bound function par baad me `.call({ name: 'Z' })` phir bhi `'C'` deta hai

Phir: `setTimeout(obj.greet, 0)` `hi undefined` log karta hai. Use **do alag tareeke** se fix karo (ek `bind` se, ek arrow wrapper se) taaki `hi A` log ho.
