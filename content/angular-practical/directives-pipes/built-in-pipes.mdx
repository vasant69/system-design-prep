<SimpleDefinition>

A pipe transforms a value for display, written in the template with the `|` operator: `{{ value | pipeName:arg }}`. Angular provides pipes for dates (`date`), currency (`currency`), numbers (`number`), percentages (`percent`), text casing (`uppercase`/`lowercase`/`titlecase`), `json` (debugging), `slice`, `keyvalue`, and the special `async` pipe that subscribes to an Observable/Promise and cleans it up automatically.

</SimpleDefinition>

## Hinglish Deep Explanation

<Hinglish>

Data aksar "raw" hota hai — `2023-04-01T00:00:00Z`, `85000`, `0.734` — par user ko "01 Apr 2023", "₹85,000.00", "73%" chahiye. Ye display-only transformation pipe se hoti hai, template me hi.

### What is it

```html
{{ employee.joinDate | date:'dd MMM yyyy' }}
{{ employee.salary | currency:'INR':'symbol':'1.0-0' }}
{{ employee.leaveRatio | percent:'1.0-1' }}
{{ employee.firstName | titlecase }}
{{ department.code | uppercase }}
{{ employee | json }}
```

- `|` operator — left value ko right pipe me bhejo.
- `:` ke baad arguments — `date:'dd MMM yyyy'`, `currency:'INR':'symbol'`.
- Chaining: `{{ name | slice:0:10 | uppercase }}`.

### Common built-in pipes

| Pipe | Example | Output |
|---|---|---|
| `date` | `x | date:'dd MMM yyyy, h:mm a'` | `01 Apr 2023, 9:30 AM` |
| `currency` | `85000 | currency:'INR':'symbol':'1.0-0'` | `₹85,000` |
| `number` | `1234.5 | number:'1.2-2'` | `1,234.50` |
| `percent` | `0.734 | percent:'1.0-1'` | `73.4%` |
| `uppercase` / `lowercase` / `titlecase` | `'anil' | titlecase` | `Anil` |
| `slice` | `list | slice:0:5` | first 5 items |
| `json` | `obj | json` | pretty JSON (debug) |
| `keyvalue` | `map | keyvalue` | `[{key, value}, ...]` for `@for` |
| `async` | `data$ | async` | latest emitted value |

Zyadatar pipes `CommonModule` se aati hain — standalone component ke `imports` me `DatePipe`, `CurrencyPipe`, `AsyncPipe`, etc. (ya poora `CommonModule`).

### The digit format string — `'1.2-2'`

`{minIntegerDigits}.{minFractionDigits}-{maxFractionDigits}`:

- `'1.2-2'` — kam se kam 1 integer digit, exactly 2 decimals.
- `'1.0-0'` — no decimals (whole rupees).
- `'1.0-2'` — 0 to 2 decimals as needed.

### The `async` pipe — special aur important

```html
@if (employee$ | async; as employee) {
  <h2>{{ employee.firstName }}</h2>
}
```

`async` pipe:

- Observable/Promise ko **subscribe** karta hai.
- Latest value template ko deta hai.
- Component destroy pe **automatically unsubscribe** — memory leak nahi.
- OnPush ke saath naturally kaam karta hai (emit pe `markForCheck`).

Isliye `.subscribe()` component me likhne se aksar `async` pipe better — cleanup free.

### Why do we need pipes — kyun

- **Formatting logic template me** — component clean, sirf raw data rakhta hai.
- **Locale-aware** — `date`/`currency`/`number` locale ke hisaab se format (₹ vs $, `,` vs `.`).
- **Reusable** — ek `date:'dd MMM yyyy'` poore app me consistent.
- **Pure by default** — Angular memoize karta hai (same input -> cached output).

### Show it in our project

`EmployeeCard`:

```html
<p>Joined: {{ employee.joinDate | date:'dd MMM yyyy' }}</p>
<p>CTC: {{ employee.salary | currency:'INR':'symbol':'1.0-0' }}</p>
<p>Leave used: {{ employee.leaveUsedRatio | percent }}</p>
```

Employee list with async:

```html
@for (emp of (employees$ | async) ?? []; track emp.id) {
  <app-employee-row [employee]="emp" />
}
```

Locale: `app.config.ts` me `{ provide: LOCALE_ID, useValue: 'en-IN' }` + `registerLocaleData(localeEnIn)` — phir `date`/`currency` Indian format me.

### Where is it used in day-to-day development

Har date, har money value, har percentage, har list ka async data. `json` pipe debugging me. `slice` "show first 3, +N more" me. `titlecase` names me. Practically har template me 3–10 pipes hote hain.

### Pros and cons

**Pros**

- Formatting declarative aur reusable.
- Locale-aware built-ins — manual formatting bugs kam.
- Pure pipes memoized — sasti.
- `async` pipe subscription lifecycle free me handle karta hai.

**Cons**

- Custom heavy pipe (ya impure) har CD cycle me chal sakta hai — perf trap.
- Pipe me business logic daalna (filtering/sorting lists) anti-pattern.
- Locale data manually register karna padta hai non-default locales ke liye.

</Hinglish>

<Callout type="trap">

List ko filter/sort karne ke liye pipe **mat** banao (`{{ items | myFilter:term }}`). Ye har CD pe chalega ya impure banana padega (aur bhi bura). Filtering/sorting component (signals/`computed`) me karo.

</Callout>

## Real World Example

<RealWorld company="Finance and HR screens">

EMS payroll screen: har row me `salary | currency:'INR'`, `joinDate | date:'dd MMM yyyy'`, `taxRate | percent:'1.1-2'`, `lastLogin | date:'short'`. Ek jagah locale `en-IN` set hai, to saari dates `dd/MM/yyyy` aur amounts `₹1,23,456.00` (Indian grouping) me consistently aati hain — koi developer manual `toLocaleString` nahi likhta, isliye ek bhi format inconsistency nahi.

## Numbers That Matter

<Numbers>

- Digit format string: `'{minInt}.{minFrac}-{maxFrac}'` — e.g. `'1.2-2'` = min 1 integer, exactly 2 fraction digits.
- `date` pipe ke predefined formats: `'short'`, `'medium'`, `'long'`, `'full'`, plus custom tokens (`dd`, `MMM`, `yyyy`, `h`, `mm`, `a`, `z`).
- Non-default locale ke liye `registerLocaleData()` + `LOCALE_ID` — warna `en-US` grouping/symbols.
- `async` pipe **ek subscription per usage** — same observable ko 3 jagah `| async` = 3 subscriptions (cold observable = 3 executions); `computed`/`shareReplay` se dedupe.

</Numbers>

## Interview Angle

<InterviewAngle>

Common: "pipe kya hai?", "`async` pipe kya karta hai aur kyun better than `subscribe`?", "pure vs impure pipe?", "pipe me list filter karna theek hai?".

Strong answer:

1. Pipe = template-level value transform via `|`; args after `:`; chainable.
2. `async` = subscribe + latest value + auto-unsubscribe on destroy + OnPush-friendly.
3. Pure (default) = memoized on input identity; impure = runs every CD (rarely needed).
4. Filtering/sorting lists via pipe = anti-pattern; do it in the component.

Red flag: "pipe me `Date.now()` ya random ke sasath dynamic output" — pure pipe stale rahega; impure banao aur samjho perf cost.

</InterviewAngle>

## Common Mistakes

<Mistake>

**`{{ salary | currency }}` bina locale register kiye Indian format expect karna.** Default `en-US` -> `$` aur `1,234,567` grouping. `LOCALE_ID` + `registerLocaleData(localeEnIn)` set karo `en-IN` ke liye.

</Mistake>

<Mistake>

**Pipe se list filter/sort karna.** `{{ employees | filterByName:term }}` — pure pipe reference-change pe hi chalega (naya filter miss), impure pipe har CD pe (slow). `computed(() => ...)` use karo.

</Mistake>

<Mistake>

**Standalone component me pipe import karna bhoolna.** `date`/`currency`/`async` -> `DatePipe`/`CurrencyPipe`/`AsyncPipe` (ya `CommonModule`) `imports` me. Bhool gaye -> "The pipe 'date' could not be found".

</Mistake>

<Mistake>

**Same observable ko kai jagah `| async` karna.** Har `| async` alag subscription. Cold observable (HTTP) 3 baar fire hoga. `computed`, `toSignal`, ya `shareReplay(1)` se ek hi execution.

</Mistake>

<Mistake>

**`{{ value | json }}` production me chhod dena.** `json` pipe sirf debugging ke liye — user ko `[object]` dump nahi chahiye.

</Mistake>

## Quick Revision

<QuickRevision>

- Pipe: `{{ value | name:arg1:arg2 }}` — display transform in the template; chainable.
- Common: `date`, `currency`, `number`, `percent`, `uppercase`/`lowercase`/`titlecase`, `slice`, `json`, `keyvalue`, `async`.
- Digit format: `'minInt.minFrac-maxFrac'`, e.g. `'1.0-0'`, `'1.2-2'`.
- Non-default locale: `registerLocaleData()` + `{ provide: LOCALE_ID, useValue: 'en-IN' }`.
- `async` pipe: subscribes, gives latest value, auto-unsubscribes on destroy, OnPush-friendly — prefer over manual `.subscribe()` in components.
- Pure pipes (default) are memoized on input identity; impure run every CD.
- Never filter/sort lists with a pipe — do it in the component (`computed`).
- Standalone components must import the pipe (`DatePipe`, `AsyncPipe`, ... or `CommonModule`).

</QuickRevision>

## Practice

<Callout type="tip">

**Chhota:** `EmployeeCard` me `joinDate | date:'dd MMM yyyy'`, `salary | currency:'INR':'symbol':'1.0-0'`, aur `leaveRatio | percent` dikhao. Format strings badal ke output changes dekho.

**Medium:** `app.config.ts` me `LOCALE_ID` `'en-IN'` set karo aur `registerLocaleData` call karo. Pehle-baad compare karo: `currency` `$` se `₹` ho jaana chahiye aur number grouping Indian (`1,23,456`).

**Bada:** Employee list ko do tarah se render karo: (a) `ngOnInit` me `service.getAll().subscribe(list => this.employees = list)` + `ngOnDestroy` unsubscribe; (b) template me `employees$ | async`. Dono se same UI. Phir `employees$ | async` ko template me **3 jagah** use karo aur network tab me dekho HTTP call 3 baar hua — `shareReplay(1)` ya `toSignal` se fix karke 1 baar karo. 5-line note.

</Callout>
