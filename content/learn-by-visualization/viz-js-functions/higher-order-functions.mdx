**Higher-Order Functions – Complete Summary**

First-class functions ka matlab: function ek value hai — variable mein rakh sakte ho, argument bana ke bhej sakte ho, return kar sakte ho. Higher-order function (HOF) wahi hai jo function ko argument leta hai, ya function return karta hai, ya dono. `map`, `filter`, `reduce`, `forEach`, `addEventListener`, `setTimeout` — sab HOF hain (function IN lete hain). Function factory, `bind`, decorator — function OUT dete hain. Fayda: "kya karna hai" (logic) ko "kaise loop/schedule karna hai" se alag kar dena, taaki chhote reusable tukde jodo.

## Visual

```text
  A) function goes IN as an argument
                          ┌──────── callback ────────┐
     [1, 2, 3].map(  n => n * 2  )                    │
        │            └─────────────┘                  │
        │   map calls the callback once per element   ▼
        └────────────────────────────▶  [2, 4, 6]

  B) function comes OUT as a return value
     function multiplier(factor) {
        return function (n) {      ◀── inner fn remembers `factor` (closure)
           return n * factor;
        };
     }
     const triple = multiplier(3)     ──▶  triple(10)  ──▶  30

  HOF  =  takes a fn   ─and / or─   returns a fn
```

## Code

```js
// 1. Takes a function IN — a tiny reusable "repeat" helper
function repeat(times, action) {
  for (let i = 0; i < times; i++) action(i); // `action` is the callback
}
repeat(3, (i) => console.log("run", i)); // run 0 / run 1 / run 2

// 2. Returns a function OUT — a factory that bakes in config
function withPrefix(prefix) {
  return (msg) => `[${prefix}] ${msg}`; // closes over `prefix`
}
const log = withPrefix("API");
console.log(log("saved")); // "[API] saved"

// 3. Both — wrap timing/logging around ANY function
function timed(fn) {
  return (...args) => {
    const out = fn(...args);
    console.log(fn.name, "done");
    return out;
  };
}
timed((a, b) => a + b)(2, 3); // logs "... done", returns 5
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | Function jo doosra function argument leta hai, ya function return karta hai, ya dono. |
| Kab/kaise hota hai | Functions first-class values hain — `map(fn)` callback andar leta hai; factory `return fn` bahar deta hai (closure ke saath). |
| Kyun useful hai | "Kya karna hai" (callback) ko "kaise loop/schedule karna hai" se alag karo — chhota, testable, reusable code. |
| Interview trap | Callback pass karte waqt `fn()` mat likho — wo turant chala kar uska result pass kar deta hai; sirf `fn` (reference) pass karo. |

## Wrong vs Right

```js
// Galat: callback ko call kar diya, reference nahi bheja
button.addEventListener("click", handleClick());
// handleClick abhi chal gaya; uska return value (undefined) listener ban gaya
```

```js
// Sahi: function reference pass karo — event pe library khud call karegi
button.addEventListener("click", handleClick);
// ya extra args chahiye to wrap karo:
button.addEventListener("click", (e) => handleClick(e, id));
```

**Ek line mein:** Higher-order function function ko data ki tarah leta ya deta hai, jisse behaviour parameterise ho jaata hai aur `map`/`filter`/factory/decorator jaise patterns possible bante hain.
