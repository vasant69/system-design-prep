**map, filter & reduce – Complete Summary**

Teen array methods jo callback lete hain aur naya result dete hain — original array kabhi change nahi hota. `map`: har element ko transform karo, length same rehti hai (n andar to n bahar). `filter`: test pass karne wale elements rakho, baaki hata do (n andar to utne ya kam bahar). `reduce`: poore array ko ek value mein "fold" karo — accumulator plus har element se naya accumulator (n andar to 1 bahar, aur wo 1 kuch bhi ho sakti hai: number, string, object, array). Teeno chain ho sakte hain: pehle `filter`, phir `map`, phir `reduce`.

## Visual

```text
  input:  [ 1,  2,  3,  4,  5,  6 ]

  ── filter(n => n % 2 === 0) ─────────────  keep only some
          │
          ▼
        [ 2,  4,  6 ]           (3 elements — shorter)

  ── map(n => n * 10) ─────────────────────  transform 1 : 1
          │
          ▼
        [ 20, 40, 60 ]          (still 3 elements — same length)

  ── reduce((acc, n) => acc + n, 0) ───────  fold to ONE value
          │
      acc: 0 ─▶ 20 ─▶ 60 ─▶ 120
          │
          ▼
          120                   (a single number)

  original array UNCHANGED at every step
```

## Code

```js
const orders = [
  { item: "pen", qty: 3, price: 10 },   // line total 30
  { item: "book", qty: 1, price: 250 }, // line total 250
  { item: "tape", qty: 2, price: 40 },  // line total 80
];

// map -> one value per order (transform, same length)
const totals = orders.map((o) => o.qty * o.price);
// [30, 250, 80]

// filter -> keep only totals of 100 or more (same or fewer)
const big = totals.filter((t) => t >= 100);
// [250]

// reduce -> fold every total into one grand total
const grand = totals.reduce((acc, t) => acc + t, 0);
// 0 -> 30 -> 280 -> 360   (result: 360)

// chain: no temp variables, original `orders` untouched
const bigRevenue = orders
  .map((o) => o.qty * o.price)
  .filter((t) => t >= 100)
  .reduce((acc, t) => acc + t, 0); // 250

console.log(totals, big, grand, bigRevenue); // [30,250,80] [250] 360 250
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | `map` = transform (n to n), `filter` = select (n to kam ya barabar), `reduce` = fold (n to 1). Teeno naya result dete hain. |
| Kab/kaise hota hai | Har method callback ko har element pe chalata hai; `reduce` mein ek extra "accumulator" chalta hai jo har step pe update hota hai. |
| Kyun useful hai | Loop plus `push` plus mutable temp variable ki jagah ek declarative pipeline — "kya ho raha hai" padhne mein saaf dikhta hai. |
| Interview trap | `reduce` mein initial value (jaise `, 0` ya `, {}`) dena mat bhoolo — empty array pe bina initial value ke `TypeError`, aur pehla element galti se acc ban jaata hai. |

## Wrong vs Right

```js
// Galat: map ko forEach ki tarah use kiya — side effect, koi transform return nahi
const names = [];
users.map((u) => { names.push(u.name); });
// `names` bhar gaya, par map ka naya array [undefined, undefined, ...] waste hai
```

```js
// Sahi: transform ke liye map, condition ke liye filter, dono chain
const activeNames = users
  .filter((u) => u.isActive)   // condition -> boolean
  .map((u) => u.name);         // transform -> value
```

**Ek line mein:** `map` shape badalta hai length nahi, `filter` length badalta hai shape nahi, `reduce` sab kuch ek value mein samet leta hai — teeno naya array/value dete hain, original ko chhedte nahi.
