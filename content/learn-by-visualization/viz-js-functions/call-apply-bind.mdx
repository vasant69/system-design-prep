**call, apply & bind – Complete Summary**

Teeno ka ek hi kaam: function ka `this` haath se set karna. `call(thisArg, a, b)` function ko turant chalata hai, args comma se. `apply(thisArg, arr)` bhi turant chalata hai, par args ek array mein. `bind(thisArg, a)` function chalata NAHI — ek naya function return karta hai jiska `this` (aur diye gaye leading args) hamesha ke liye fix ho jaate hain, jise tum baad mein kabhi bhi call kar sakte ho. Yaad rakhne ka trick: **c**all = **c**omma, **a**pply = **a**rray, **b**ind = **b**aad mein.

## Visual

```text
  function greet(greeting, mark) {
    return greeting + ", " + this.name + mark;
  }
  const user = { name: "Asha" };

        ┌───────────────────────────────────────────────┐
        │  greet("Hi", "!")          this ──▶ undefined  │   ✗
        └───────────────────────────────────────────────┘

  call    greet.call(user, "Hi", "!")      this ──▶ user   RUN NOW  ▶ "Hi, Asha!"
  apply   greet.apply(user, ["Hi", "!"])   this ──▶ user   RUN NOW  ▶ "Hi, Asha!"
  bind    const g = greet.bind(user, "Hi") this ──▶ user   NOT YET
          g("!")                                           ▶ "Hi, Asha!"

  same function ──▶ this re-pointed 3 ways ──▶ call/apply run, bind waits
```

## Code

```js
function introduce(city, role) {
  return `${this.name} from ${city}, works as ${role}`;
}

const dev = { name: "Neha" };

// call -> run now, args listed one by one
console.log(introduce.call(dev, "Pune", "SDE"));
// "Neha from Pune, works as SDE"

// apply -> run now, args as ONE array (handy when args already sit in an array)
console.log(introduce.apply(dev, ["Delhi", "QA"]));
// "Neha from Delhi, works as QA"

// bind -> no call; returns a NEW fn with `this` + leading args locked
const nehaInBlr = introduce.bind(dev, "Bengaluru");
console.log(nehaInBlr("DevOps"));
// "Neha from Bengaluru, works as DevOps"

// classic apply use: spread an array into a variadic fn (pre-spread syntax)
console.log(Math.max.apply(null, [4, 9, 2])); // 9
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | Har function pe teen methods jo `this` ko explicitly set karte hain. |
| Kab/kaise hota hai | `call` = comma args + turant run. `apply` = array args + turant run. `bind` = naya function, `this` fix, run baad mein. |
| Kyun useful hai | Method borrowing (`Array.prototype.slice.call(args)`), callback ka `this` lock karna, partial application (`bind` se leading args fix). |
| Interview trap | `bind` kiye hue function ko dobara `bind`/`call` karne se `this` nahi badalta — pehla `bind` jeet jaata hai. Arrow function pe teeno `this` ignore karte hain. |

## Wrong vs Right

```js
// Galat: method ko object se nikaal kar pass kiya -> `this` toot gaya
const account = {
  balance: 500,
  show() { console.log(this.balance); },
};
setTimeout(account.show, 100);
// undefined  (`account.show` ab bare function hai, `this` !== account)
```

```js
// Sahi: bind se `this` ko account pe lock karo
const account = {
  balance: 500,
  show() { console.log(this.balance); },
};
setTimeout(account.show.bind(account), 100);
// 500
```

**Ek line mein:** `call` aur `apply` `this` set karke function ko abhi chala dete hain (farak sirf args comma vs array), jabki `bind` ek naya `this`-locked function return karta hai jise tum baad mein chalate ho.
