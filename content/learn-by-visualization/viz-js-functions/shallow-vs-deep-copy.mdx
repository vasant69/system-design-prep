**Shallow vs Deep Copy – Complete Summary**

Object/array copy karne pe do level hote hain. **Shallow copy**: naya top-level container banta hai, par uske andar ke nested objects/arrays sirf reference se copy hote hain — matlab copy aur original pehle level ke neeche sab kuch share karte hain. `{ ...obj }`, `Object.assign({}, obj)`, `arr.slice()`, `[...arr]` — sab shallow. **Deep copy**: har level recursively clone hota hai, dono bilkul independent. Modern built-in `structuredClone(obj)`; jaldi ka jugaad `JSON.parse(JSON.stringify(obj))` (functions, `undefined`, `Date`, `Map`, `BigInt` pe tootta hai); ya library helper.

## Visual

```text
  original = { id: 1, tags: ["a", "b"] }

  SHALLOW  copy = { ...original }
  ┌── copy ────────────┐        ┌── original ───────┐
  │ id: 1  (new)       │        │ id: 1             │
  │ tags: ●────────────┼───┬────┼─▶ ["a", "b"]      │
  └────────────────────┘   │    └───────────────────┘
                           └── SAME array: copy.tags === original.tags

     copy.tags.push("c")  ──▶  original.tags bhi ["a","b","c"]   ✗

  DEEP  copy = structuredClone(original)
  ┌── copy ─────────────────┐     ┌── original ────────────┐
  │ id: 1                   │     │ id: 1                  │
  │ tags: ●──▶ ["a","b"] new│     │ tags: ●──▶ ["a","b"]   │
  └─────────────────────────┘     └────────────────────────┘
     whole tree cloned  ──▶  changes never leak            ✓
```

## Code

```js
const original = {
  id: 1,
  meta: { views: 10 },
  tags: ["js", "copy"],
};

// SHALLOW — spread copies only the top level
const shallow = { ...original };
shallow.id = 99;              // safe: primitive, its own copy
shallow.meta.views = 500;     // LEAKS: same nested object
console.log(original.meta.views); // 500  (not 10!)

// DEEP — structuredClone recurses through every level
const deep = structuredClone(original);
deep.meta.views = 7;
deep.tags.push("deep");
console.log(original.meta.views); // 10   (untouched)
console.log(original.tags);       // ["js", "copy"]

// JSON hack — works here, but drops functions / undefined / Date / Map
const jsonCopy = JSON.parse(JSON.stringify(original));
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | Shallow = naya top-level, nested reference share hota hai. Deep = har level clone, poori independence. |
| Kab/kaise hota hai | `{ ...o }`, `Object.assign`, `slice`, `Array.from` = shallow. `structuredClone`, JSON round-trip, recursive helper = deep. |
| Kyun useful hai | Immutable state update ke liye sirf us level tak copy chahiye jise tum badal rahe ho; full deep copy tab jab poora nested data alag karna ho (snapshot, undo). |
| Interview trap | `JSON.parse(JSON.stringify(x))` functions, `undefined`, `Date` (string ban jaati hai), `Map`/`Set`, `BigInt` (throw), aur circular refs (throw) pe fail karta hai. |

## Wrong vs Right

```js
// Galat: config ka "copy" banake mutate kiya — shared default bhi badla
const DEFAULTS = { retry: { count: 3 } };
function makeConfig(over) {
  const c = { ...DEFAULTS, ...over };
  c.retry.count = 0;   // DEFAULTS.retry.count bhi ab 0 — shallow copy!
  return c;
}
```

```js
// Sahi: jitne level mutate ho rahe hain utne copy karo
function makeConfig(over) {
  const c = structuredClone(DEFAULTS);
  return { ...c, ...over };
}
// ya sirf zaroori branch: { ...DEFAULTS, retry: { ...DEFAULTS.retry, count: 0 } }
```

**Ek line mein:** Shallow copy sirf pehla level naya banata hai (nested abhi bhi shared), deep copy poora tree clone karta hai — `structuredClone` use karo, JSON-trick sirf plain JSON-safe data pe.
