**Promise.all, race, allSettled & any – Complete Summary**

Chaaron static methods kai promises ko ek saath chalakar ek result mein badal dete hain. `Promise.all` — sab fulfil ho to values ka array; koi ek reject to poora turant reject (fail-fast). `Promise.allSettled` — kabhi reject nahi karta; har promise ka `status` ke saath `value` ya `reason` deta hai. `Promise.race` — jo pehla settle ho (fulfil ya reject), wahi result. `Promise.any` — jo pehla fulfil ho wo result; sab reject ho tabhi `AggregateError` se reject.

## Visual

```text
3 promises:   P1 ✓200ms    P2 ✗100ms    P3 ✓300ms

Promise.all([P1, P2, P3])
   P2 reject @100ms ──▶ REJECT (P2 reason)   baaki ignore   [fail-fast]

Promise.allSettled([P1, P2, P3])
   sab ka wait ──▶ FULFIL @300ms
   [ { status: "fulfilled", value: v1 },
     { status: "rejected",  reason: e2 },
     { status: "fulfilled", value: v3 } ]        kabhi reject nahi

Promise.race([P1, P2, P3])
   P2 pehle settle @100ms ──▶ REJECT (P2)   pehla jo bhi settle

Promise.any([P1, P2, P3])
   P2 reject skip ──▶ P1 fulfil @200ms ──▶ FULFIL (v1)
   (sab reject hote to -> AggregateError)
```

## Code

```js
const ok = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));
const bad = (ms, e) =>
  new Promise((_, rej) => setTimeout(() => rej(new Error(e)), ms));

// all: ek reject -> poora reject
await Promise.all([ok(50, "a"), bad(20, "x")]).catch((e) => e.message); // "x"

// allSettled: sabka hisaab, kabhi reject nahi
const r = await Promise.allSettled([ok(50, "a"), bad(20, "x")]);
// [ { status: "fulfilled", value: "a" }, { status: "rejected", reason: Error } ]

// race: pehla settle (yahan reject) jeeta
await Promise.race([ok(50, "a"), bad(20, "x")]).catch((e) => e.message); // "x"

// any: pehla fulfil jeeta, reject skip
await Promise.any([bad(20, "x"), ok(50, "a")]); // "a"
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | 4 static combinators: `all`, `allSettled`, `race`, `any` — N promises se ek result. |
| Kab/kaise hota hai | `all` aur `any` pehle fail ya success se decide; `race` pehle settle pe; `allSettled` sabke settle pe. |
| Kyun useful hai | Parallel fetches (`all`), best-effort dashboards (`allSettled`), timeout (`race`), mirror/fallback servers (`any`). |
| Interview trap | `race` reject pe bhi settle ho jaata hai — timeout ke liye sahi, "fastest success" ke liye galat; wahan `any`. |

## Wrong vs Right

```js
// Galat: independent fetches ko sequential await -> slow, aur ek fail sab rok deta
const users = await getUsers();
const stats = await getStats(); // users ke baad shuru
const feed = await getFeed(); // stats ke baad
```

```js
// Sahi: ek saath fire; partial failure OK ho to allSettled
const [users, stats, feed] = await Promise.all([
  getUsers(),
  getStats(),
  getFeed(),
]); // parallel; koi ek fail -> catch mein poora
```

**Ek line mein:** `all` = sab ya pehla fail, `allSettled` = sabka status kabhi fail nahi, `race` = pehla settle, `any` = pehla success.
