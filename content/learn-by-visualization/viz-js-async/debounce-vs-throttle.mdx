**Debounce vs Throttle – Complete Summary**

Debounce aur throttle dono rapid events (typing, scroll, resize) pe function ki call frequency kam karte hain. Debounce: har naya event timer ko reset karta hai, aur function tabhi chalta hai jab events ek fixed quiet gap ke liye ruk jaayein — search box ke liye perfect. Throttle: function ko har interval mein zyaada se zyaada ek baar chalao, chahe events baraste rahein — scroll, mousemove aur drag ke liye perfect. Dono ek closure use karte hain jisme timer ya last-run timestamp rehta hai. Yaad rakhne ka tareeka: debounce = "jab ruk jao", throttle = "har X ms mein ek baar".


## Code

```js
// DEBOUNCE — sirf aakhri call, quiet gap ke baad
function debounce(fn, delay) {
  let timer; // closure mein rehta hai
  return function (...args) {
    clearTimeout(timer); // har call pe pichla cancel
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

// THROTTLE — har interval mein sirf ek baar
function throttle(fn, interval) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= interval) {
      last = now;
      fn.apply(this, args); // window khula -> chalao
    } // warna chup-chaap ignore
  };
}

const onSearch = debounce((q) => api.search(q), 300); // typing ruke -> 1 call
const onScroll = throttle(() => updateHeader(), 200); // scroll pe har 200ms
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | Debounce = events ruknay ke baad 1 call; throttle = har interval mein max 1 call. |
| Kab/kaise hota hai | Debounce har event pe timer reset karta hai; throttle last-run timestamp ya flag check karta hai. |
| Kyun useful hai | Search/autocomplete/validate ke liye debounce; scroll/resize/mousemove/infinite-scroll ke liye throttle. |
| Interview trap | Search box pe throttle lagana galat — beech ke keystrokes pe bhi call jaayegi; wahan debounce chahiye. |

## Wrong vs Right

```js
// Galat: search input pe seedha listener -> har keystroke = 1 API call
input.addEventListener("input", (e) => api.search(e.target.value));
// "laptop" type kiya -> 6 requests, race conditions, rate-limit
```

```js
// Sahi: debounce -> typing ruke tabhi ek call
const search = debounce((v) => api.search(v), 300);
input.addEventListener("input", (e) => search(e.target.value));
// "laptop" -> 1 request, 300ms baad
```

**Ek line mein:** Debounce function ko events ruknay ke baad ek baar chalata hai (search box), throttle use har interval mein zyaada se zyaada ek baar chalata hai (scroll) — dono closure aur timer se bante hain.
