**Hoisting & the TDZ – Complete Summary**

JS har scope ko do phase mein chalata hai. Phase 1 (creation) mein engine poora scope scan karke saare declarations ke liye jagah bana deta hai: `var` ko `undefined` milta hai, function declaration poori-ki-poori ready ho jaati hai, `let`/`const`/`class` ke naam reserve to hote hain par "uninitialised" rehte hain. Phase 2 (execution) mein code line-by-line chalta hai aur assignments ab hoti hain. Isi "naam pata hai par value abhi nahi" wale gap ka naam hai Temporal Dead Zone (TDZ) — `let`/`const` ko unki declaration line se pehle chhoona `ReferenceError` deta hai, `typeof` bhi. Function declaration ko define se pehle call kar sakte ho; function expression (`const f = () => {}`) ko nahi.

## Visual

```text
  SOURCE ORDER                    PHASE 1: CREATION  (scan only, no code runs)
  ─────────────────────────       ─────────────────────────────────────────────
  console.log(a)                  var a         ──▶  a  = undefined
  console.log(fn())               function fn   ──▶  fn = <whole function body>
  console.log(b)                  let b         ──▶  b  = <uninitialised>  ┐
  var a = 1                                                                │ TDZ
  function fn() { return 2 }                                               │
  let b = 3                       ─────────────────────────────────────────┘

                                  PHASE 2: EXECUTION  (run line by line)
                                  ─────────────────────────────────────────────
  console.log(a)      ──▶  undefined        (name reserved, value not set yet)
  console.log(fn())   ──▶  2                (fn was hoisted whole)
  console.log(b)      ──▶  ReferenceError   (b still inside its TDZ)
  var a = 1           ──▶  a = 1
  let b = 3           ──▶  b = 3    ◀── TDZ for b ends exactly on this line
```

## Code

```js
// PHASE 1 reserves names; PHASE 2 assigns values as lines execute.

greet();               // "hi"      -> function DECLARATION hoisted whole
console.log(count);    // undefined -> var name reserved, not yet assigned
// console.log(city);  // ReferenceError -> `city` (let) is in the TDZ here

function greet() {      // usable before this line: hoisted in phase 1
  console.log("hi");
}

var count = 10;         // phase 2: `count` becomes 10 on this line
let city = "Pune";      // the TDZ for `city` ends right here

// A function EXPRESSION is NOT callable early:
// pay();               // TypeError: pay is not a function
var pay = function () { console.log("paid"); };
// `var pay` was hoisted as undefined; the function is assigned only now.
```

## Point vs Short baat

| Point | Short baat |
|---|---|
| Kya hai | Har scope 2 phase mein chalta hai: pehle creation (saare naam reserve), phir execution (value assign). Declaration "upar chali gayi" jaisa lagta hai — yahi hoisting hai. |
| Kab/kaise hota hai | `var` reserve hota hai `undefined` ke saath. Function declaration poori hoist hoti hai. `let`/`const`/`class` reserve hote hain par TDZ mein, apni declaration line par initialise. |
| Kyun useful hai | Function declaration ko define se pehle call kar sakte ho (helper functions file ke neeche rakhna, mutual recursion). TDZ ka `ReferenceError` "declare se pehle use kiya" bug turant loud kar deta hai. |
| Interview trap | `typeof x` bhi TDZ mein crash karta hai, jabki kabhi declare na hue naam par `typeof` chup-chaap `"undefined"` deta hai. Aur `var` ki hoisting silent `undefined` deti hai, error nahi. |

## Wrong vs Right

```js
// Galat: function EXPRESSION ko uski assignment line se pehle call kiya
init();
var init = function () { console.log("ready"); };
// Output: TypeError: init is not a function
// (`var init` undefined ke saath hoist hua; function value abhi assign nahi hui)
```

```js
// Sahi: function DECLARATION use karo (ya call ko declaration ke baad rakho)
init();
function init() { console.log("ready"); }
// Output: "ready"   -> declaration phase 1 mein poori ready ho jaati hai
```

**Ek line mein:** Hoisting matlab har scope pehle saare naam register karta hai (`var` = `undefined`, function declaration = poori, `let`/`const` = TDZ) aur phir line-by-line values assign karta hai.
