Do pages: `HomeComponent` aur `AboutComponent`. Inhe Angular Router jodta hai. Trace karna hai: **route table**, `<router-outlet>`, `routerLink` click, aur component ka swap — sab bina full page reload ke.

## Files

```ts
// app/home.component.ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-home',
  template: `<h2>Home</h2><p>Welcome to the home page.</p>`,
})
export class HomeComponent {}
```

```ts
// app/about.component.ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-about',
  template: `<h2>About</h2><p>This is the about page.</p>`,
})
export class AboutComponent {}
```

```ts
// app/app-routing.module.ts  — the ROUTE TABLE
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home.component';
import { AboutComponent } from './about.component';

const routes: Routes = [
  { path: '', component: HomeComponent },        // URL "/"        -> HomeComponent
  { path: 'about', component: AboutComponent },  // URL "/about"   -> AboutComponent
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],       // register routes at app root
  exports: [RouterModule],                       // re-export so AppModule gets the directives
})
export class AppRoutingModule {}
```

```ts
// app/app.module.ts
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { AppComponent } from './app.component';
import { AppRoutingModule } from './app-routing.module';
import { HomeComponent } from './home.component';
import { AboutComponent } from './about.component';

@NgModule({
  declarations: [AppComponent, HomeComponent, AboutComponent],
  imports: [BrowserModule, AppRoutingModule],    // <-- routing module wired in here
  bootstrap: [AppComponent],
})
export class AppModule {}
```

```html
<!-- app/app.component.html  — the shell -->
<nav>
  <a routerLink="">Home</a>
  <a routerLink="/about">About</a>
</nav>

<!-- the router renders the matched component right here -->
<router-outlet></router-outlet>
```

## Step-by-Step Flow Trace

**Setup phase:**

1. App boot hota hai. `AppModule` ke `imports` me `AppRoutingModule` hai, isliye wo bhi load hota hai.
2. `AppRoutingModule` `RouterModule.forRoot(routes)` call karta hai. Isse Router service configure hota hai us `routes` array ke saath, aur `forRoot` ek app-wide Router instance banata hai.
3. `AppComponent` render hota hai. Uske template me `<router-outlet></router-outlet>` hai — ye ek directive hai (RouterModule se aayi) jo ek jagah "mark" karti hai jahan matched component render hoga.
4. `routerLink` bhi ek directive hai (RouterModule se), jo `<a>` tags par lagi hai. Wo normal browser navigation ko rok deti hai aur click par Router ko bolegi.

**Initial navigation:**

5. Router current URL dekhta hai. Maan lo `/` hai.
6. Router `routes` array me match dhoondhta hai: `{ path: '', component: HomeComponent }` match hua.
7. Router `HomeComponent` ka instance banata hai aur use `<router-outlet>` ke **theek baad** DOM me daal deta hai (outlet khud ek marker hai, component uske sibling ki tarah aata hai).
8. Screen par: nav links + "Home / Welcome to the home page."

**User navigation:**

9. User "About" link click karta hai.
10. `routerLink="/about"` directive default `<a>` behaviour (browser ka page reload) ko `preventDefault` kar deti hai.
11. Directive Router ko `navigateByUrl('/about')` (effectively) call karti hai.
12. Router `/about` ke liye `routes` me match dhoondhta hai: `{ path: 'about', component: AboutComponent }`.
13. Router **guards/resolvers** check karta hai (yahan koi nahi hain), phir current outlet component (`HomeComponent`) ko destroy karta hai.
14. Router `AboutComponent` ka instance banata hai aur use outlet ki jagah render kar deta hai.
15. Browser ki address bar `/about` ho jaati hai (Router `history.pushState` use karta hai — isliye koi full reload nahi, back button bhi kaam karega).
16. Change detection chalta hai, screen par ab "About / This is the about page."

## One-Line Wiring Summary

`RouterModule.forRoot(routes)` URL-to-component ka table register karta hai, `<router-outlet>` batata hai kahan render karna hai, aur `routerLink` ka click browser reload ke bajaye Router ko trigger karta hai — jo purana component hata kar matched component uski jagah laga deta hai.

## Self-Check Questions

1. `app.component.html` se `<router-outlet></router-outlet>` hata do par routes waise hi rahein — "About" link click karne par kya dikhega aur kyun?
2. `routerLink="/about"` ki jagah plain `href="/about"` likhein to behaviour kaise badlega?
3. Step 13-14 me `HomeComponent` ka instance destroy hota hai aur `AboutComponent` ka naya banta hai — iska matlab agar tum `HomeComponent` par wapas aao, to kya wo apni purani state yaad rakhega?
