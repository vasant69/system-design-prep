Ye sabse pehla wiring hai — ek hi component (counter), koi service nahi, koi routing nahi. Maqsad: `index.html` se lekar screen par number badalne tak ka poora rasta dekhna.

## Files

```html
<!-- index.html -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>Counter</title>
  </head>
  <body>
    <!-- Angular isi custom tag ke andar app "mount" karega -->
    <app-root></app-root>
  </body>
</html>
```

```ts
// main.ts  — the JavaScript entry point the bundler runs first
import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';
import { AppModule } from './app/app.module';

platformBrowserDynamic()
  .bootstrapModule(AppModule)          // "start the app using this root module"
  .catch(err => console.error(err));
```

```ts
// app/app.module.ts  — the root NgModule: the app's "table of contents"
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],       // components this module owns
  imports: [BrowserModule],           // other modules this module needs
  bootstrap: [AppComponent],          // the component to mount into <app-root>
})
export class AppModule {}
```

```ts
// app/app.component.ts  — the root component: class + template + selector
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',               // MUST match the tag in index.html
  templateUrl: './app.component.html',
})
export class AppComponent {
  count = 0;                          // component state

  increment() {                      // called from the template on click
    this.count++;
  }
}
```

```html
<!-- app/app.component.html  — the root component's view -->
<h1>Counter</h1>
<p>Current value: {{ count }}</p>
<button (click)="increment()">+1</button>
```

## Step-by-Step Flow Trace

1. Browser `index.html` load karta hai. Usme `<app-root></app-root>` ek khaali custom tag hai — abhi iske andar kuch nahi.
2. Bundler ka banaya hua JavaScript chalta hai aur uska entry point `main.ts` hai.
3. `main.ts` `platformBrowserDynamic().bootstrapModule(AppModule)` call karta hai. Iska matlab: "browser platform taiyaar karo aur app ko `AppModule` se shuru karo."
4. Angular `AppModule` ke `@NgModule` metadata ko padhta hai. `bootstrap: [AppComponent]` dekh kar use pata chalta hai ki root component `AppComponent` hai.
5. Angular `AppComponent` ka `@Component` metadata padhta hai. `selector: 'app-root'` mila.
6. Angular DOM me `<app-root>` tag dhoondhta hai (jo `index.html` me hai), `AppComponent` class ka ek instance banata hai (`count = 0`), aur uska template us tag ke andar render kar deta hai.
7. Template render hote waqt `{{ count }}` ki jagah `0` aa jaata hai, aur `(click)="increment()"` button ke click event ko component ke `increment()` method se jod deta hai.
8. Ab screen par dikhta hai: "Current value: 0" aur ek "+1" button.
9. User "+1" click karta hai. Browser ek click event fire karta hai.
10. Angular (Zone.js ke through) is event ko intercept karta hai, `increment()` chalata hai, `this.count` `0` se `1` ho jaata hai.
11. Method return hone ke baad Angular **change detection** run karta hai: component tree ghoomta hai, har binding re-check karta hai.
12. `{{ count }}` ki nayi value (`1`) purani (`0`) se alag hai, isliye Angular sirf us text node ka DOM update kar deta hai. Screen par ab "Current value: 1".

## One-Line Wiring Summary

`index.html` ka `<app-root>` tag + `main.ts` ka `bootstrapModule` + `AppModule` ka `bootstrap` array + `AppComponent` ka matching `selector` — ye chaar cheezein milkar ek class ko screen par ek live, event-driven view bana deti hain.

## Self-Check Questions

1. Agar `app.component.ts` me `selector` `'app-root'` se badal kar `'my-app'` kar do par `index.html` me `<app-root>` hi rahe, to kya hoga aur kyun?
2. `AppModule` ke `declarations` aur `bootstrap` arrays me `AppComponent` dono me hai — har ek ka kaam kya hai?
3. Button click ke baad `{{ count }}` ki value screen par update kis step par hoti hai — `increment()` chalne par, ya uske baad kisi aur cheez par?
